# Telegram AI Hub for Odoo

![Telegram AI Hub](telegram_ai_hub/static/description/cover.png)

Telegram AI Hub turns Telegram into a secure AI assistant for Odoo. Authorized
employees can ask business questions, retrieve live records, send voice requests
and execute approved actions while Odoo access rights and explicit bot permissions
remain enforced.

## Product demo

[Watch or download the English narrated Full HD live demo](telegram_ai_hub/static/description/demo_en.mp4)

The demo contains real chatbot requests executed against a live Odoo database,
including contact creation, CRM opportunity creation and business-data retrieval.

## Main features

- One complete installable Odoo application;
- guided BotFather, webhook and AI-provider setup;
- modern operations dashboard and connection health monitoring;
- authorized Telegram employees linked to internal Odoo users;
- granular permissions for contacts, CRM, sales and accounting;
- natural-language and voice-message processing;
- invoice, payment, sales order, product, stock, CRM and calendar queries;
- controlled creation of contacts, leads and opportunities;
- configurable commands, keywords, workflows and AI steps;
- conversation management, human handover and full audit history.

## Requirements

- Odoo Community or Enterprise on Odoo.sh or an on-premise server;
- public HTTPS endpoint for the Telegram webhook;
- Telegram bot created with the official BotFather;
- customer-supplied OpenAI API key for AI responses and voice transcription.

## Compatibility

Version-specific branches are available for Odoo 11.0 through 19.0.

## External services

The application sends bot messages through the Telegram Bot API. When AI features
are enabled, the content needed to answer a request or transcribe a voice message
is sent to the AI endpoint configured by the customer. API credentials are supplied
and controlled by the customer. Provider terms, privacy policies and usage charges
are separate from the module purchase.
