Frequently asked questions

Is installation assistance included?

Yes. We accompany customers during installation and initial configuration, including the Telegram bot, webhook, AI provider and first authorized user.

Can employees access every record in Odoo?

No. Requests use the linked Odoo user's security context and are additionally restricted by explicit Telegram permissions and allow-listed tools.

Does it support voice messages?

Yes. Telegram voice messages can be transcribed by the configured AI provider and handled like text requests.

Are Telegram and OpenAI fees included?

Telegram bot usage is normally free. OpenAI usage is billed separately by the provider to the customer using the configured API key.

Which deployment types are supported?

Odoo Community and Enterprise on Odoo.sh or on-premise servers with a public HTTPS endpoint. Odoo Online does not allow custom server modules.

External services and data processing

The customer supplies and controls the Telegram bot and AI API key. Messages sent to the AI assistant are transmitted to the configured AI endpoint for processing. Telegram and AI-provider terms, privacy policies and usage charges remain separate. Administrators must inform users and obtain any consent required by applicable law.
